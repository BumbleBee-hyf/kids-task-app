# 大转盘恶搞奖品 + 超级大奖 - 完成总结

## 变更概要

修改大转盘奖品分布：移除 20 元，新增恶搞奖品（12.5%）和 100 元超级大奖（0.5%），服务端从均匀随机改为加权随机。

### 新奖品分布

| 奖品                     | 权重 | 概率  |
| ------------------------ | ---- | ----- |
| 1 元                     | 37   | 37%   |
| 2 元                     | 25   | 25%   |
| 5 元                     | 12.5 | 12.5% |
| 10 元                    | 12.5 | 12.5% |
| 恶搞（🪰/💩/🐍/🐛 随机） | 12.5 | 12.5% |
| 100 元                   | 0.5  | 0.5%  |

### 三层展示效果

| 层级     | 弹窗标题      | 图标 | 动画                                   |
| -------- | ------------- | ---- | -------------------------------------- |
| 普通金钱 | 🎉 恭喜中奖！ | 🎉   | 彩纸飘落                               |
| 恶搞     | 😂 恶搞奖品！ | 😂   | emoji 展示                             |
| 超级大奖 | 🏆 超级大奖！ | 🏆   | 金色彩纸 + 弹窗脉冲发光 + 金额弹跳缩放 |

## 核心设计决策

- 服务端和客户端统一使用加权随机算法，概率完全一致
- 100 元扇区在转盘上可见（红色 + 🏆 图标 + 金色边框），视觉上与普通扇区区分
- 恶搞奖品不发放代金券，100 元正常发放
- 超级大奖弹窗有独立的金色脉冲发光、金额弹跳动画和金色彩纸效果
