# 顶部导航栏重构设计文档

## 1. 设计目标

将现有侧边栏布局全面重构为顶部导航栏布局，完全对标用户提供的参考截图风格。

## 2. 布局架构

### 2.1 顶部导航栏 (Top Navbar)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 🎒 学生中心   每日任务·快乐成长   🏠首页  📋我的任务  🎰抽奖中心 💰我的钱包   👤 小黄豆 ▼ │
│                          ────                                        │
└──────────────────────────────────────────────────────────────────────┘
```

**左侧品牌区**

- Emoji 图标（学生🎒/家长👨‍👩‍👧）+ 品牌名 "学生中心"/"家长中心"
- 下方小字标语："每日任务 · 快乐成长" / "陪伴成长 · 见证进步"

**中间导航区**

- 导航项：图标 + 文字，水平排列
- 当前页底部有橙色下划线指示器
- hover 时文字变橙色

**右侧用户区**

- 用户头像（绿色圆形渐变）+ 显示名 + 下拉箭头
- 点击可展开退出菜单

**样式**

- 背景：白色，底部 1px 暖色边框
- 高度：约 64px
- 阴影：`0 2px 12px rgba(0,0,0,0.06)`
- 固定定位（sticky top）

### 2.2 主内容区

- 无左侧 margin，全宽展示
- 背景保持 `var(--bg-page)` 奶油色
- 顶部 padding 需要为固定导航栏留出空间

## 3. 页面组件改造

### 3.1 学生首页 (StudentDashboard)

参考截图结构：

#### 欢迎卡片

```
┌────────────────────────────────────────────────────────────────────┐
│  ┌──┐  你好，小黄豆！                                              │
│  │👦│  今天又是美好的一天 😊 加油鸭！                                │
│  └──┘                                    ┌────────┐ 连续签到        │
│                                          │📅    3 │ 天      >       │
│                                          └────────┘                │
└────────────────────────────────────────────────────────────────────┘
```

- 整体为一个渐变背景卡片（暖色米白到浅橙渐变）
- 左侧：圆形用户头像（大，约 72px）
- 中间：加粗大号问候语 + 小号鼓励语
- 右侧：签到区域（日历图标 + "连续签到 X 天" + 箭头）

#### 页面标题区

```
┌────────────────────────────────────────────────────────────────────┐
│  🏠 学生首页                                    ┌──────────┐       │
│                                                 │🎁签到领积分│       │
│                                                 └──────────┘       │
└────────────────────────────────────────────────────────────────────┘
```

- 左侧：emoji + "学生首页"（大字粗体）
- 右侧："签到领积分" 按钮（橙色 outline 风格）

#### 统计卡片

- 三列等宽卡片，带图标、数字、标签、箭头
- 橙色卡：📌 待完成任务 0 →
- 蓝色卡：💰 代金券余额 25 →
- 绿色卡：🎰 今日剩余抽奖 0 →
- 数字使用大号粗体，颜色与卡片主题一致

#### 今日统计

- 白色卡片，标题带图标
- 三列：已提交 | 已通过 | 今日获得积分
- 用竖线 `|` 分隔
- 通过数和积分数字带颜色

#### CTA 按钮

- 两列网格：橙（去做任务）+ 绿（去抽奖）
- 大按钮、圆角、阴影、hover 上浮

### 3.2 家长首页 (ParentDashboard)

- 同样的顶部欢迎卡片（问候语不同）
- 三列统计：已发布任务、待审批、今日已审批
- 同样的今日统计 + CTA 按钮
